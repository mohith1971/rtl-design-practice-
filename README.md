# RTL Design Practice

Digital hardware designs implemented using SystemVerilog.

## Tools
- SystemVerilog
- Icarus Verilog
- VVP Simulator

## Projects

### 01 - Arithmetic
- Full Adder
- 4-bit Ripple Carry Adder (hierarchical design)

### 02 - Combinational Logic
- 2:1 Multiplexer
- 4-bit 2:1 Multiplexer
- 4:1 Multiplexer
- 2:4 Decoder

Each design includes a separate testbench.
